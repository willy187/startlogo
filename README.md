# StartLogo

Chrome extension that replaces the logo on the Google search home page with your own text
(Korean, Japanese, Chinese, emoji), an image, or a live clock.

구글 검색 첫 화면의 로고를 한글·일본어·중국어·이모지 텍스트, 내 이미지, 실시간 시계로 바꾸는 크롬 확장 프로그램입니다.

- Website / 소개 페이지: see `docs/index.html` (published with GitHub Pages)
- Privacy policy / 개인정보처리방침: see `docs/privacy.html`
- Extension source / 확장 프로그램 소스: `extension/`

## Privacy

StartLogo does not collect, transmit or sell any data. Settings are stored only in your own browser.
